<h1 style="text-align: center; color: #cdb783; font-style: header; font-family: 'Noto Serif Georgian'; font-weight: bold; font-size: 70px">The Lineage Dressage Method</h1>
<div style="text-align: center; color: #cdb783; font-style: italic;">The Grimoire does not house isolated patterns; it documents a living bloodline. Our dressage is built upon an ancient family tree of movement. Every advanced maneuver you witness in the arena is a direct descendant of a simpler, foundational action. To master the apex drills, you must first honor the ancestors from which they belong.</div>

> [!custom-question-type] 
> **The Lineage Method** treats dressage not as a scattered collection of maneuvers, but as a living ancestral bloodline. In this discipline, every advanced drill descends directly from a singular, foundational movement known as the **Progenitor**. By tracing branches down the family tree—altering an axis, layering a timing split, or introducing a rotational pivot—a core maneuver gives birth to complex **Descendant** variations. To execute an apex pattern in the arena, a rider must first master the root from which it was born; if the foundational stride fractures, the entire bloodline collapses.

<h1 style="text-align: center; color: #cdb783; font-style: header; font-family: 'Noto Serif Georgian'; font-weight: bold; font-size: 30px">Code of the Arena</h1>

> [!multi-column]
> 
>> [!blank-container] 
>> #### Ⅰ. Voice Priority & Chat Protocol
>> All commands, countdowns, and real-time corrections are delivered via **Discord voice call**. In-game chat must remain clear during active practices.
>
>> [!blank-container] 
>> #### Ⅱ. The Dot System `.`
>> If you have an urgent question or need clarification, type a single period (`.`) in the in-game club chat. This signals the instructor to pause or hold the next command until your question is addressed.
>
>> [!blank-container] 
>> #### Ⅲ. Mistake & Desync Protocol (Immediate Halt)
>> If you miss a call, desync, or lose track of the pattern, **halt immediately in place** (unless stated otherwise). Remain completely still until the current move finishes so you do not collide with active tracks. Re-align with the formation once the line resets or straightens.

> [!multi-column]
> 
>> [!blank-container] 
>> #### Ⅳ. Spacing Adjustment (Gait Shifting)
>> To correct spacing gaps, transition temporarily into a **walk** (if crowding) or a **canter** (if lagging). **Never cut corners or drift off the line** to fix your gap—keep your hooves in the leader's tracks at all times.
>
>> [!blank-container] 
>> #### Ⅴ. Mount Readiness
>> Horses must enter the arena fully cared for/fed, max level (or level 13), and outfitted in designated club tack before practice start times.
>
>> [!blank-container] 
>> #### Ⅵ. AFK Area
>> If stepping away, notify the instructor between sets and park your mount entirely outside the arena boundary rails. 

<h1 style="text-align: center; color: #cdb783; font-style: header; font-family: 'Noto Serif Georgian'; font-weight: bold; font-size: 30px">How to Read a Grimoire Scroll (Visual Legend)</h1>

Every move entry follows a uniform template:

- **✧ [TITLE]:** The official name of the maneuver called in practice.
- **˖ [Rank]:** The difficulty tier or vault housing the move _(e.g., Gilded Gates, Fledgling Descent, Sanguine Corridor, Eternal Vault)_.
- **˖ [*type of move*]:** The movement family / lineage branch (Axis, Orbit, Eclipse, Phantom).
- **╰╮ [definition]:** The concise description of how to execute the maneuver and its path across the arena.
- **︰ [Moves required]:** Ancestral prerequisites needed prior to attempting this move. For origin moves, this displays `None` or `Progenitor`.
- **︰ [#Fundamentals]:** The technical fundamentals practiced within the move (e.g., #Spacing, #Alignment, #PivotPoint).
- **︰ [Modifiers]:** Command tags accepted by this move (e.g., Wave, Double, Left/Right).
- **✧ [Alignment]:** The technical fundamentals practiced within the move (e.g., Boot-to-Boot, Half-Horse, Full Pocket).
- **˖ ♫ [*Gait*]:** Mandatory baseline speed/gait for the pattern.
- **╰╮ [Credit]:** The original creator or dressage dictionary the move was adapted from, linked directly to their reference page.


<h1 style="text-align: center; color: #cdb783; font-style: header; font-family: 'Noto Serif Georgian'; font-weight: bold; font-size: 30px">Move Modifiers</h1>

> [!custom-question-type]
> Move modifiers are functional tags attached to base commands that alter execution without changing the underlying move structure.

| Category       | Modifier                   | Function                                       | Example Call           |
| :------------- | :------------------------- | :--------------------------------------------- | :--------------------- |
| **Direction**  | **Left / Right (`L`/`R`)** | Designates turn or curl side                   | `[Curl L... GO]`       |
|                | **In / Out**               | Directs toward arena center or rail            | `[Comb In... GO]`      |
|                | **Away**                   | Alternating peel to opposing sides             | `[Cut Away... GO]`     |
| **Repetition** | **Double / Triple**        | Consecutive executions without restraightening | `[Double Curl... GO]`  |
|                | **Delay / Wave**           | One-stride staggered execution down the line   | `[Wave Curl... GO]`    |
| **Gait**       | **Walk / Trot / Canter**   | Overrides standard card gait                   | `[Canter Curl... GO]`  |
|                | **Halt**                   | Full stop on pattern completion                | `[Curl to Halt... GO]` |
